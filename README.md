# Nandini — Personal Portfolio

A production-oriented React/Vite portfolio for Nandini Kurdekar.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

Portfolio content lives in `src/data/site.js`.

The project list was based on Nandini's accessible GitHub repositories. No fabricated metrics, internships, certifications, live demos, or professional experience are included.
